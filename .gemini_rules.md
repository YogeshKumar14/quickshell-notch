# Project Rules & Learned Behaviors

## Hyprland Custom Config Rules
1. **Lua Precedence**: Note that Hyprland v0.56+ natively prefers `hyprland.lua` over `hyprland.conf` when both are present in `~/.config/hypr/`. Always verify the active configuration file using logs.
2. **Dual-Format Persistence**: Write settings overrides to both `quickshell_hypr.conf` and `quickshell_hypr.lua` to guarantee settings persistence across all Hyprland configurations.
3. **MPRIS Time Conversions**: MPRIS playback position and track length are measured in microseconds. Convert to seconds (divide by 1,000,000) for UI display.
